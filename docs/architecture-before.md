# Architecture before the redesign (snapshot of `main` @ e62d249)

Graphify (Graphify-Labs/graphify, CLI `graphifyy` 0.9.106, local AST, no LLM) was run on `src/`:
Affitti-Mamma, multichain, Thesis), so `/graphify` could not map it.

## Stack
Next 15.2.4 (Turbopack dev), React 19.0, Tailwind 4, next-intl 4 (`it` default, `en`),
framer-motion, react-masonry-css, AWS SDK (S3 list + CloudFront signed URLs), exifr,
plaiceholder, date-fns. npm lockfile (plus a stray `pnpm` dependency). **No database,
no Prisma, no auth, no tests, no vitest, no zod, no shadcn.**

## Routes
- `/[locale]` home (client component; fetches `/data/*.json` in `useEffect`)
- `/[locale]/portfolio` photo gallery (client; lists S3 keys then one metadata call per photo)
- `/[locale]/contacts` (placeholder page)
- `GET /api/images-list?path=` lists S3 keys under any prefix
- `GET /api/image?filename=` signs a CloudFront URL for any key + fetches its `.json` sidecar

## Content
- UI copy: `public/languages/{it,en}.json`; structured data: `public/data/*.json`
- Photos: S3 bucket behind CloudFront; EXIF/blur sidecar JSON generated by a Lambda
  (`src/app/api/image/lamda_function.py`, `metadata.py`, untracked)

## Dependency map
```
layout -> Header(theme, language) / Footer / ThemeProvider / NextIntlClientProvider
home   -> SkillsTags, SocialButton, S3Image, IconMap
portfolio -> Gallery -> S3Image -> /api/image -> CloudFront + S3 sidecar
```

## Graphify result (`graphify update src`, commit 17a5c57)
116 nodes, 251 edges, 7 communities, 100% EXTRACTED, no import cycles.
God nodes: `Link` (15), `getIcon()` (15), `HomePage()` (8), `Header()` (8), `S3Image()` (6).
Communities: layout/nav, home + gallery, Lambda EXIF extractor (duplicated in `metadata.py` and
`lamda_function.py`), icon map/theme/contacts, `/api/image` + S3 helpers.
Full report and graph: `docs/graphify-before/` (`graph.json`, `GRAPH_REPORT.md`).
Takeaway: the whole UI hangs on `getIcon` (a hand-made icon map) and `S3Image` (metadata fetch +
lightbox in one 211-line client component); both are replaced by shadcn/lucide and a server-rendered gallery.
